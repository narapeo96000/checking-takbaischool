# คู่มือการใช้งาน

สำหรับครูที่ปรึกษาและผู้ดูแลระบบ คู่มือนี้อ่านได้จากเมนู **คู่มือการใช้งาน** ของแอปก่อนเข้าสู่ระบบ และพิมพ์หรือบันทึกคู่มือเป็น PDF ได้จากปุ่มด้านบน

ผู้ดูแลระบบต้องบันทึกอีเมลของครูแต่ละบัญชีในเมนู **ตั้งค่า → จัดการผู้ใช้งาน** อีเมลนี้ใช้ขอรหัสรีเซ็ตเมื่อจำรหัสผ่านไม่ได้ ระบบส่งรหัสใช้ครั้งเดียวและหมดอายุภายใน 15 นาที โดยไม่แสดงว่าชื่อผู้ใช้มีอยู่หรือไม่

ลิงก์ Web App ที่เผยแพร่แล้วกำหนดใน `config.js` หน้าเว็บเริ่มตรวจการเชื่อมต่ออัตโนมัติ ให้รอข้อความเชื่อมต่อสำเร็จก่อนเข้าสู่ระบบ การเปิดเว็บไซต์หรือมีลิงก์ที่บันทึกไว้ยังไม่ยืนยันว่าฐานข้อมูลพร้อม โหมดข้อมูลตัวอย่างใช้ข้อมูลสมมุติ ไม่บันทึกลง Google Sheet และไม่เก็บพิกัดจริง

## เริ่มใช้จากมือถือ

1. เปิดลิงก์ระบบในเบราว์เซอร์ของโทรศัพท์ ตรวจอินเทอร์เน็ต เมนูบนมือถือเปิดด้วยปุ่มสามขีด
2. เข้าสู่ระบบด้วยบัญชีที่โรงเรียนมอบให้ หากเป็นรหัสผ่านชั่วคราวต้องตั้งใหม่ก่อนใช้งาน รหัสผ่านยาว 12–128 ตัวอักษร
3. เปิด **เช็คชื่อ** ตรวจวันที่ซึ่งเริ่มต้นเป็นวันนี้ตามเวลาไทย แล้วเลือกห้องที่ได้รับมอบหมาย
4. รอรายชื่อโหลด อนุญาตพิกัด แล้วเลือกสถานะพร้อมเหตุผลของนักเรียนแต่ละคน
5. ตรวจแถบสถานะว่า **บันทึกแล้ว** และไม่มีรายการรอซิงก์ก่อนปิดงาน

ครูเข้าถึงข้อมูลเฉพาะห้องที่ได้รับมอบหมาย ผู้ดูแลจัดการโรงเรียน บัญชี ห้อง นักเรียน และประวัติ หากไม่มีห้องหรือเข้าไม่ได้ให้ติดต่อผู้ดูแล อย่าใช้บัญชีของครูคนอื่น

## เช็คชื่อและพิกัด

| สถานะ | ความหมาย |
| --- | --- |
| มา | มาเรียนตามปกติ |
| ขาด | ไม่มาและไม่มีการลาตามข้อมูลที่ตรวจสอบ |
| สาย | มาช้ากว่าเวลาโรงเรียนกำหนด นับรวมผู้มาเรียน |
| ลา | ลาตามข้อมูลที่ได้รับ ให้บันทึกเหตุผล |
| ยังไม่เช็ค | ยังไม่เลือกสถานะ ไม่ถือว่าขาด |

เลือกสถานะก่อนพิมพ์เหตุผล หยุดพิมพ์สักครู่ให้ระบบส่งอัตโนมัติ การแก้ไขอัปเดตรายการเดิมของนักเรียนในวันนั้นและเก็บประวัติไว้ เลือกวันย้อนหลังได้ตามสิทธิ์ แต่ไม่รับการเช็คชื่อล่วงหน้า

ปุ่ม **มาครบ** เปลี่ยนทุกคนในห้องเป็นมา รวมคนที่เคยเลือกขาด สาย หรือลา ต้องยืนยันก่อนใช้ ปุ่ม **ล้างข้อมูล** ล้างสถานะและเหตุผลของห้องในวันที่เลือก ไม่ลบทะเบียนและยังมีประวัติก่อนล้าง

พิกัดเก็บจากโทรศัพท์ของผู้บันทึกพร้อมค่าความแม่นยำเป็นเมตร ตัวเลขมากหมายถึงคลาดเคลื่อนได้มาก เมื่อเปลี่ยนสถานที่ให้เก็บพิกัดใหม่ หากปฏิเสธสิทธิ์หรือหาไม่ได้ ระบบเก็บเหตุแทน พิกัดใช้ประกอบการตรวจย้อนหลัง ไม่รับรองว่าผู้ใช้ยืนอยู่ในจุดนั้นแน่นอน

## บันทึกอัตโนมัติและรายการค้าง

**กำลังบันทึก** คือรอคำยืนยัน **บันทึกแล้ว** คือระบบยืนยัน ส่วน **รอส่งข้อมูล / รอซิงก์** ยังอยู่ในโทรศัพท์และยังไม่บันทึกลง Sheet

หากโหลดห้องไว้แล้วและเน็ตหลุด การแก้สถานะ/เหตุผลเก็บรอส่งในเครื่องเดิม ใช้เครื่องและบัญชีเดิมเมื่อกลับมาออนไลน์แล้วกดซิงก์ ระบบนี้ไม่เก็บรายชื่อทั้งโรงเรียนเพื่อเปิดห้องใหม่แบบออฟไลน์

รายการค้างเก็บได้ไม่เกิน **24 ชั่วโมง** และล้างเมื่อกู้คืนรายการเก่า ต้องซิงก์ให้สำเร็จภายในวันเดียวกัน อย่าล้างข้อมูลเบราว์เซอร์ เปลี่ยนเครื่อง หรือใช้โหมดส่วนตัวระหว่างมีรายการค้าง

เมื่อมีการแก้ไขจากอีกอุปกรณ์ ให้เทียบ **ข้อมูลบนเซิร์ฟเวอร์** กับ **รายการในเครื่อง** ทั้งวันที่ ห้อง สถานะ และเหตุผล หากยืนยันใช้รายการในเครื่องต้องกดซิงก์อีกครั้ง หากยังไม่แน่ใจให้เก็บไว้ตรวจสอบภายหลังและประสานครูอีกคน การยืนยันรายการล้างข้อมูลจะล้างการเช็คชื่อทั้งห้องของวันนั้น

## หน้าหลักและสถิติ

หน้าหลักแสดงยอดสถานะ ความคืบหน้า และข้อมูลรายห้อง เปลี่ยนวันที่ดูวันอื่นได้ อัตรามาเรียนคำนวณ **(มา + สาย) ÷ จำนวนรายการที่ควรเช็คชื่อ × 100** เช่น 40 คน มา 34 สาย 2 ได้ 90% รายการยังไม่เช็คอยู่ในตัวหาร จึงควรเช็คให้ครบก่อนใช้รายงาน

สถิติหลายวันนับจำนวนครั้งต่อวัน ไม่ใช่จำนวนคนไม่ซ้ำทั้งเดือน ใช้วันที่มีรายการเช็คชื่อหรือชุดเช็คชื่อในช่วงที่เลือก วันที่ไม่มีการบันทึกเลยไม่ถูกนับ ยังไม่มีปฏิทินวันเรียนและทะเบียนย้อนหลังแยกภาคเรียน จึงต้องตรวจฐานจำนวนก่อนใช้เป็นสถิติทางการ

1. เปิด **สถิติ** เลือกช่วงวันที่หรือเดือน หากเลือกเดือนระบบใช้ช่วงเดือนนั้น
2. เลือกห้องหรือครูที่ปรึกษา เว้นว่างเพื่อดูทุกห้องที่บัญชีมีสิทธิ์
3. การค้นหารายคนต้องใส่เลขประจำตัวนักเรียน ใช้คำค้นเพิ่มเติมช่วยกรองได้
4. กดค้นหา ตรวจตัวกรองและข้อมูลก่อนส่งออก หากไม่พบให้ล้างเงื่อนไขที่ไม่จำเป็นและตรวจวันที่อีกครั้ง

## รายงาน PDF

ซิงก์รายการค้างก่อน ที่หน้าหลักเลือกวันที่ หรือที่สถิติเลือกตัวกรองและค้นหา จากนั้นกด **ส่งออก PDF** ดูไฟล์ในรายการดาวน์โหลดของโทรศัพท์และตรวจข้อมูลก่อนส่งต่อ

ระบบจริงเก็บ PDF ในโฟลเดอร์โรงเรียน ดาวน์โหลดผ่านบัญชีแอปได้ ลิงก์ Drive ส่วนตัวต้องใช้บัญชี Google ที่ได้รับการแชร์ โฟลเดอร์ต้องตั้ง Restricted หากรายงานใหญ่ให้ลดช่วงหรือเลือกห้องเดียว

โหมดตัวอย่างใช้หน้าต่างพิมพ์ของเบราว์เซอร์ เลือกบันทึกเป็น PDF ข้อมูลยังเป็นตัวอย่าง ปุ่มพิมพ์คู่มือพิมพ์เฉพาะคู่มือ PDF มีข้อมูลนักเรียนและอาจมีพิกัด ให้ส่งเฉพาะผู้เกี่ยวข้อง

## นักเรียน ห้อง และบัญชี

ครูใช้เมนู **รายชื่อนักเรียน** กรองห้อง ครูที่ปรึกษา หรือค้นหาชื่อ/เลขประจำตัว หากทะเบียนผิดให้แจ้งผู้ดูแลก่อนเช็คชื่อ

ผู้ดูแลเตรียมตามลำดับ:

1. ตั้งค่า → จัดการผู้ใช้งาน เพิ่มบัญชีครูและกำหนดสิทธิ์
2. จัดการห้องเรียน เพิ่มรหัสห้อง ชื่อห้อง ครูที่ปรึกษา และเปิดสถานะใช้งาน
3. รายชื่อนักเรียน → เพิ่มนักเรียน กรอกเลขประจำตัว คำนำหน้า ชื่อ นามสกุล เลขที่ และห้อง
4. ตรวจศูนย์นำหน้าของเลขประจำตัว อย่านำรหัสเดิมไปใช้กับอีกคน แก้ชื่อ ห้อง เลขที่ และสถานะผ่านปุ่มแก้ไข
5. ใช้สถานะไม่ใช้งานเมื่อนักเรียนพ้นทะเบียนและตรวจผลต่อรายงานย้อนหลัง

## ตั้งค่าและแจ้งเตือน

ผู้ดูแลกรอกข้อมูลโรงเรียน สังกัด ที่อยู่ อีเมล เว็บไซต์ โลโก ผู้อำนวยการ และรองผู้อำนวยการไม่เกิน 3 คน เลือกสีหลัก/สีรอง เช่นแดง–น้ำเงิน ตั้งเวลารายงาน เช่น 08:10 น. แล้วบันทึก

การแจ้งเตือนปิดเริ่มต้น เปิดเมื่อได้รับอนุญาตให้ส่งและกรอกผู้รับแล้ว LINE ใช้ Messaging API ไม่ใช้ LINE Notify เดิม Telegram ต้องมี bot และ Chat ID Chatbot ใช้ปลายทาง HTTPS กรอก token เฉพาะช่องลับ ไม่ใส่ในลิงก์หรือส่งในกลุ่มสนทนา ช่องว่างคง token เดิมที่บันทึกไว้

เวลาเป็นเป้าหมาย อาจล่าช้า ระบบพยายามแต่ละช่องทางหนึ่งครั้งต่อวัน หากไม่มีรายงานให้ตรวจผู้รับ การเปิดสรุป และประวัติ ไม่ส่งซ้ำอัตโนมัติเมื่อผลเครือข่ายไม่ชัดเจน

การติดตั้งครั้งแรกและการกู้บัญชีผู้ดูแลให้ผู้ติดตั้งดำเนินการตาม [คู่มือติดตั้ง](DEPLOYMENT.md) ครูไม่ต้องแก้ Sheet หรือสร้างโครงการเอง ไม่มีบัญชีหรือรหัสผ่านจริงเผยแพร่ในคู่มือ

## ประวัติและออกจากระบบ

ผู้ดูแลเปิด **ตั้งค่า → ประวัติการใช้งาน** ตรวจเวลา ผู้กระทำ เป้าหมาย พิกัด ความแม่นยำ และรายละเอียดก่อน/หลังแก้ไข ข้อมูลเก็บในชีต `logs` ผู้แก้ไขไฟล์ Google ยังแก้ Sheet ได้ จึงต้องจำกัดผู้แก้ไขและสำรองตามรอบ

ตรวจไม่มีรายการค้างแล้วออกจากระบบเมื่อใช้เสร็จ หากยืนยันออกทั้งที่ค้าง รายการยังอยู่ให้บัญชีเดิมบนเครื่องเดิมซิงก์ภายใน 24 ชั่วโมง การออกจากระบบไม่ได้ยืนยันว่าได้ส่งข้อมูลแล้ว

## แก้ปัญหา

| ปัญหา | วิธีตรวจ |
| --- | --- |
| ไม่มี Web App | ติดต่อผู้ดูแล ลิงก์ Sheet/Pages ใช้แทนไม่ได้ ทดลองข้อมูลตัวอย่างได้ |
| เชื่อมต่อไม่ได้ | ตรวจเน็ตและลิงก์ลงท้าย `/exec` หากใช้ Google หลายบัญชี ให้ลองหน้าต่างไม่ระบุตัวตนใหม่หรือโปรไฟล์ที่มี Google บัญชีเดียว ผู้ดูแลตรวจ deployment และสิทธิ์ Google |
| ลืมรหัสผ่าน/บัญชีถูกปิด | ติดต่อผู้ดูแล ตรวจชื่อและภาษาแป้นพิมพ์ อย่าใช้บัญชีคนอื่น |
| ไม่มีห้องหรือนักเรียน | ตรวจมอบหมายห้อง บัญชี และทะเบียนใช้งาน ไม่มีรายชื่อจริงเพิ่มอัตโนมัติ |
| พิกัดไม่ได้ | อนุญาตตำแหน่งของโทรศัพท์/เบราว์เซอร์ ใช้ HTTPS แล้วเก็บใหม่ |
| ค้างรอซิงก์ | ใช้เครื่องและบัญชีเดิม ตรวจเหตุผิดพลาดและข้อมูลขัดแย้งก่อนยืนยัน |
| PDF ไม่เปิด | ดูดาวน์โหลด ลดช่วงรายงาน และตรวจสิทธิ์บัญชี Google หากใช้ลิงก์ Drive |
| แจ้งเตือนไม่มา | ผู้ดูแลตรวจผู้รับ เวลา ช่องทาง และประวัติผลส่ง |

ไม่ต้องเปิด Google Sheet เป็นสาธารณะเพื่อให้ครูใช้แอป ให้ครูเข้าผ่านบัญชีระบบและรักษาสิทธิ์ไฟล์ของโรงเรียน

เบราว์เซอร์ที่รองรับจะแยกการเชื่อมต่อด้วย `credentialless` ออกจากคุกกี้และข้อมูลบัญชี Google เดิมตาม [คำอธิบาย MDN](https://developer.mozilla.org/en-US/docs/Web/API/HTMLIFrameElement/credentialless) หากยังเชื่อมต่อไม่ได้หรือขึ้นหน้าไม่พบเพจ ให้ลองเปิดเว็บในหน้าต่างไม่ระบุตัวตนใหม่ หรือโปรไฟล์ที่มี Google บัญชีเดียว แล้วเข้าด้วยบัญชีของแอปตามปกติ Google แนะนำวิธีแยกบัญชีเมื่อเกิด [ปัญหา multi-login](https://developers.google.com/apps-script/guides/support/troubleshooting#issues_with_multiple_google_accounts)

เปลี่ยนหน้าต่างหรือโปรไฟล์ก่อนเริ่มเช็คชื่อ หากมีรายการรอซิงก์ต้องกลับไปส่งจากเบราว์เซอร์และบัญชีเดิมให้หมดก่อน เพราะรายการค้างไม่ย้ายไปยังหน้าต่างส่วนตัวใหม่
